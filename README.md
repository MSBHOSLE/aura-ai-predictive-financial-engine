A full-stack predictive financial engineering platform combining a **React dashboard** with an **ML-driven FastAPI backend**. Implements time-series cash-flow forecasting, multi-scenario Monte Carlo simulations, and real-time risk volatility scoring.

---

## ⚡ Highlights

- **Predictive Projections**: Dynamic linear regression trends with seasonal variance bands ($+15\%$ Best Case, $-15\%$ Worst Case).
- **Interactive Scenarios**: Real-time sensitivity sliders evaluating revenue growth vs. capital expenditure impacts.
- **RESTful ML Endpoints**: High-speed FastAPI inference engine.
